# CFD_but_actually_fun

A from-scratch DirectX 12 water-physics sandbox, inspired by (not affiliated
with) classic jet-ski racing games. Clean-room implementation.

## Build
- Windows 10/11, Visual Studio 2022, "Desktop development with C++" workload
- Open CFD_but_actually_fun.sln, set x64 / Debug, run with Ctrl+F5
  (running from VS matters: the working directory must contain the .hlsl files)

## Status
Milestone 2: D3D12 device, swap chain, wireframe water grid with camera.
